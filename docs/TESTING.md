# Тестирование

## Автоматические проверки

```bash
npm run typecheck
npm run build
```

CI (`.github/workflows/ci.yml`) дополнительно запускает собранный сервер, проверяет `/api/health` и отдачу PWA, прогоняет сквозной тест защит и собирает Docker-образ.

## Тест безопасности

```bash
npm run build -w server
cd server && DATA_DIR=./data-test node dist/index.js &          # dev-режим: админ admin/admin
node test/security-smoke.mjs http://127.0.0.1:3000
```

Проверяет: тикет вместо пароля, пароли сетей, захват чужой метки, запись в объекты чужой сети, блокировку PIN, отзыв токенов (КИК), токен завершённой сети, фильтр GPS-телепортов, дедупликацию чата из офлайн-очереди.

## Локальная проверка сервера

```bash
npm run build -w server
cd server && DATA_DIR=./data node dist/index.js
```

Откройте `http://localhost:3000` → «Админ-панель» (`admin` / `admin` в dev-режиме) → создайте сеть с паролем и двух бойцов, войдите ими в двух вкладках.

Проверьте:

- [ ] Командир рисует зону, вторая вкладка видит её сразу.
- [ ] Рядовой не может нарисовать зону (ошибка `Only leaders can draw zones`).
- [ ] Сообщение в канал SQUAD не видно игроку другого отделения.
- [ ] Метка противника с TTL 2m исчезает через 2 минуты.
- [ ] После перезагрузки вкладки зоны, метки и чат на месте.

## Полевой тест перед игрой (обязательно)

Проведите на реальном VPS и реальных телефонах, в том числе с мобильным интернетом.

**Связь**

- [ ] `https://<домен>/api/health` возвращает `{"ok":true}`.
- [ ] Два телефона на LTE разных операторов слышат друг друга.
- [ ] Двое жмут PTT на одном канале: второй получает «Канал занят».
- [ ] Squad: Alpha не слышит Bravo. Platoon: слышат все.
- [ ] Roger beep у передающего, щелчок и хвост шума у принимающего.

**Фон (APK)**

- [ ] Заблокируйте экран на 10 минут. Позиция обновляется у остальных раз в ~15 с.
- [ ] С заблокированным экраном вас слышно и вы слышите.
- [ ] Кнопка проводной гарнитуры при заблокированном экране включает передачу.
- [ ] Bluetooth-гарнитура: режим «Press = start / stop», одно нажатие начинает, второе завершает.

**Фон (браузер)**

- [ ] Android Chrome: экран выключен, входящий голос слышен. GPS в браузере при выключенном экране не гарантирован. Для этого нужен APK.
- [ ] iOS Safari: фоновая работа ограничена системой. Используйте Combat mode.

**Батарея**

- [ ] Eco mode: 1 час игры с заблокированным экраном. Запишите расход батареи в %/ч для своих моделей телефонов.
- [ ] Combat mode: экран не гаснет, шапка показывает `COMBAT`.

**Офлайн-карта**

- [ ] Скачайте область, включите авиарежим, карта отображается.

## Нагрузка

Нагрузочный тест не проводился. Локальный smoke-тест показал рассылку позиции другим клиентам за ~13 мс. Узкое место при росте — исходящий трафик голоса: кадр говорящего (µ-law, 128 кбит/с) отправляется каждому слушателю канала, на 50 слушателей это ~6.4 Мбит/с исходящего канала сервера.
